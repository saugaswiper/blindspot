## Goal
Make `fetchPrimaryStudiesForScreening` return primary studies only: also drop Network Meta-Analyses and
narrative reviews, so the screening workbench's top window is not dominated by non-primary content.

## Why now
It is the earliest unbuilt step in the operator build order. Validation 007 marked the claim "screening
workbench receives only primary studies" as `partially verified`; this closes it. Cheap, one function, no ops dependency.

## Files to touch
- `lib/pubmed.ts` — `fetchPrimaryStudiesForScreening` (~line 233) only: extend the term to
  `(${query}) NOT systematic[sb] NOT "meta-analysis"[pt] NOT "network meta-analysis"[pt] NOT review[pt]`
  (binary NOT, per validation 006 F4 — never `AND NOT`). Factor the exclusion suffix into one exported
  const so it is unit-testable.
- `lib/pubmed.test.ts` (or the existing `lib/primary-study-count.test.ts` pattern) — term-construction tests.
- `spec/validation/` — harness script only if needed to measure the ACs below (live PubMed, no new secrets).

## Scope
**In:** screening feed term only; a pub-type breakdown measurement on the validation-007 topic.
**Out (explicit):**
- `fetchPrimaryStudyIds`, `countPrimaryStudies`, `countPrimaryStudiesRecent` — the recall/count path is
  **unchanged**, so the verified 80% (4/5) Mitchell 2012 recall cannot regress.
- Any ranking/ML change (brief 010), UI changes, relevance-vs-date sort changes.

## Acceptance criteria (beat, don't match)
Measured live on validation 007's insomnia topic, top-20 (and top-100) of the screening feed:
1. **AC1** NMA / Meta-Analysis publication types in top-100: **0** (007 baseline: 1 NMA in top-20).
2. **AC2** Narrative-review ("Review" pt, not RCT/trial) share of top-20: **≤ 2/20** (007 baseline: 16/20).
3. **AC3** RCT / Clinical Trial publication types in top-20: **≥ 5/20** (007 baseline: 0/20). Report the number honestly if missed; do not tune the query to the topic.
4. **AC4** Zero regression: `fetchPrimaryStudyIds` output and the Mitchell 2012 union recall (4/5) are byte-identical to before (existing tests + recorded run).
5. **AC5** Binary-NOT partition check: primaries(new term) + excluded-types ≈ primaries(old term) (≤1% discrepancy), proving the new NOTs exclude only intended types.
6. Tests: term contains no `AND NOT`; exclusion const exported; ≥3 new unit tests; `tsc`, lint, build clean.

## Claim discipline
Mark AC1–3 `claimed` until a validation run measures them. Note the known trade-off: `review[pt]` can drop a
rare mis-tagged primary study; quantify the dropped set (sample 20) in the handoff rather than asserting zero.
