## Goal
Given page text of a randomised trial, answer the **RoB 2** signalling questions per domain, **each answer
backed by a verbatim quote that is checked against the source**, then derive the domain and overall
judgments with the **published RoB 2 algorithm in code** (never an LLM-asserted "Low/High"). Backend only.

## Why this beats Otto-SR (not just matches)
Otto-SR reports judgments with justifications. We add what a black box can't: (1) every supporting quote is
mechanically verified present on its cited page, so fabricated justification is impossible to ship as
`verified`; (2) domain/overall judgment is a deterministic function of the answers, so it is auditable and
reproducible; (3) uncertainty routes to `check`/`manual`, never a guess.

## Scope
**In:** RoB 2 (parallel-group RCT, effect of assignment, domains 1–5 + overall). Per signalling question:
answer ∈ {Y, PY, PN, N, NI, NA} + `quote` + `page`. Status per question: `verified` (quote found on cited page
via `checkSourcePresence`-style matching AND the two framed passes agree) / `check` / `manual`.
Domain + overall judgment from the algorithm; any `check`/`manual` input answer that could change the result
makes the judgment `provisional` (shown, flagged). Output carries disclosure: AI-assisted, advisory, human
must confirm (RAISE).
**Out:** ROBINS-I, NOS, QUADAS-2, cluster/crossover RoB 2 variants, per-outcome multi-result handling, UI,
DB persistence, GRADE, trial-registry cross-check for domain 5 (follow-on brief).

## Acceptance criteria (bar in bold)
1. **Algorithm exactness:** `rob2-algorithm.test.ts` covers **100% of answer combinations** for all five domains; **0 mismatches** vs. the RoB 2 guidance tables (cite the table in each test).
2. **No fabricated justification:** adversarial stub returns invented quotes for every question → **0 questions `verified`**; 100% flagged with a distinct failure code (`quote_not_in_source` vs `wrong_page`).
3. **Bounded time:** stalled-model stub finishes **< 300 s** (target ≈ budget, mirroring 126), HTTP 200, all questions `manual` with `model_timeout`.
4. **Honest degradation:** every question with answer `NI` or `check`/`manual` status that can change the domain result sets that domain `provisional`; unit-tested on **≥ 5 domain/answer cases**.
5. **Typecheck/lint/build clean; all new tests pass; no regressions** in the existing suite (12 pre-existing failures unchanged).
6. **Claimed, for the tester (do not mark verified):** agreement with published Cochrane-review RoB 2 judgments on **≥ 20 RCTs across ≥ 3 reviews** — target **overall-judgment quadratic-weighted κ ≥ 0.6 and 0 `verified`-status questions whose quote is absent from the source**. Handoff must list this as `claimed`; validation brief to follow.
